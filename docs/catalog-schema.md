# Data Catalog Schema

This document outlines the schema for the data catalog used in the Restaurant Recommendation System. The clean data generated by Phase 1 (`data/processed/restaurants.parquet`) follows this structure.

## `RestaurantClean` Schema

| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `name` | String | The name of the restaurant. |
| `location` | String | The physical location/area of the restaurant. |
| `cuisines` | List[String] | A list of cuisines offered by the restaurant. |
| `cost_for_two` | Float | The approximate cost for two people to eat there. |
| `rating` | Float | The aggregated rating of the restaurant (e.g., out of 5). |
| `votes` | Integer | The total number of votes or reviews the restaurant has received. |
